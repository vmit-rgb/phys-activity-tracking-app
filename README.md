# phys-activity-tracking-app

Щоденник руху й самопочуття, який живе у твоєму телефоні. Застосунок (PWA) нікуди не надсилає твої записи: вони зберігаються тільки на телефоні, а копію ти зберігаєш сама або сам.

**Статус:** бета 0.9, у розробці.

Це щоденник, а не медична програма. Він не ставить діагнозів і не радить лікування.

## Що тут важливо знати
- Без аналітики, телеметрії й звітів про помилки. Хостинг (GitHub Pages) бачить IP-адреси відвідувачів, як будь-який сайт.
- Шрифти лежать у цьому репозиторії, тож під час роботи застосунок нічого не запитує в Google.
- Особисті дані ніколи не потрапляють у цей репозиторій. Тести працюють на вигаданих даних.

## Для розробки
Потрібен Node.js (версія в `.nvmrc`).

```sh
npm ci          # встановити залежності точно за lock-файлом
npm run dev     # локальний сервер
npm run check   # типи, тести, збірка
```

Залежності зафіксовано точними версіями, яким щонайменше два тижні. Скрипти встановлення пакетів вимкнено (`.npmrc`). GitHub Actions закріплено на хешах комітів.

Дизайн-токени (кольори обох тем, 9 акцентів, відступи, текст × 1.2, зони тапу 48/56) лежать у `src/styles/tokens.css`, базові компоненти — у `src/styles/components.css` і `src/ui/`. Усе це взято з файлу Figma. Аркуш компонентів у всіх станах: `components.html` (на сайті — `/components.html`).

Підтримка: iOS 15.4+ (iPhone 6s і новіші) та Chrome 105+. На старіших телефонах спрощено лише одне: текст натиснутої кнопки не стає напівпрозорим.

Робота йде через pull request: кожна зміна в `main` проходить перевірку (`check`) і перегляд, після чого `deploy` публікує сайт на GitHub Pages.
